## 💡 1. The Real-World Problem
Millions of neighborhood kirana stores, boutiques, and small business owners run on informal credit (*udhaar*). Every single day, they manage accounts on crumpled paper notebooks (*bahi-khata*):
- **Manual Calculation Headaches:** Calculating who owes how much across 100+ customers takes hours every weekend.
- **Lost Revenue:** Shopkeepers forget to follow up on overdue amounts or feel awkward asking for money.
- **The Cloud Privacy Dilemma:** Shopkeepers **cannot and will not** upload their neighbors' personal debt records and phone numbers to proprietary cloud LLMs (OpenAI, Anthropic).
- **The API Tax:** Paying commercial cloud vision APIs ($0.03–$0.05/image) makes small business software unprofitable.

---

## 🚀 2. The Solution: KhataSnap AI
**KhataSnap** is an open-source, privacy-first AI workflow that bridges the gap between old paper ledgers and modern instant payment recovery:

```
Handwritten Khata Page 
       ↓
Open-Weight Vision Extraction (Local Gemma 2 / Ollama)
       ↓
Side-by-Side Human Verification Interface (You approve all amounts!)
       ↓
Deterministic Digital Ledger (Arithmetic in code, zero LLM math errors)
       ↓
Culturally Respectful Hinglish Payment Reminders (Polite, Friendly, Urgent)
       ↓
1-Click WhatsApp Follow-Up & Recovery Pipeline (wa.me)
```

## ✨ 3. Core Features Built

### 1. Smart Khata Scanner & Side-by-Side Reviewer (Hero Screen)
- Upload any photo of a handwritten register or click our authentic pre-loaded Bahi-Khata samples.
- **Interactive Split View:**
  - *Left:* High-resolution handwritten register with visual bounding highlight boxes.
  - *Right:* Editable structured cards (Customer, Date, Items, Amount, +Udhaar / -Jama).
- **Ambiguity Detection:** Flags unclear ink strokes or overwriting (e.g., *"₹450 vs ₹950"*) for manual verification before saving.
- **Celebratory Approval:** Confetti animation upon batch confirmation.

### 2. Verified Customer Ledger & Digital Passbook
- Individual customer accounts with calculated balances:  
  $$\text{Current Balance} = \text{Total Udhaar} - \text{Total Jama}$$
- **Zero AI Math Errors:** Balances are computed deterministically in code, not generated by an LLM.
- **Customer Passbook Modal:** Itemized debit/credit passbook view with 1-click **Print Passbook** and **CSV Export**.
- **+ Record Direct Transaction:** Quick modal for recording cash or counter payments.

### 3. Hinglish Payment Reminder Hub (WhatsApp Ready)
- Pulls verified database balance directly into culturally respectful reminders:
  - **Namaste (Polite):** *"Namaste Rahul ji! Aapke khate mein ₹1,250 ka balance pending hai. Jab aapko suvidha ho, kripya dukaan par ya UPI se payment kar dein. Dhanyavaad!"*
  - **Friendly:** Casual check-in for regular patrons.
  - **Official Notice:** For delayed or 30-day+ accounts.
  - **Urgent:** Overdue priority alert.
- **1-Click WhatsApp Send:** Direct `https://wa.me/{phone}?text=...` deep link integration.
- Copy to clipboard with instant feedback.

### 4. Capital Recovery Tracker & Dashboard
- **Total Outstanding Capital** locked in market udhaar.
- **Payments Recovered This Month** with recovery efficiency percentage.
- **Overdue Watchlist** identifying customers needing immediate follow-up.
- **Verified Transaction Audit Trail** saved persistently to local database storage.

### 5. Privacy-First Local AI & Open Innovation Lab
- **Local Ollama Daemon Detection:** Live status check on `http://localhost:11434` for **Gemma 2**.
- **Embedded Privacy Engine:** High-fidelity local fallback that guarantees 100% functionality on any machine without cloud API keys.
- **Zero-Cloud Guarantee:** Customer debts, names, and phone numbers never leave the user's computer.

## 🏃 5. How to Run Locally

### Prerequisites
- Node.js (v18 or higher)
- *(Optional for live local LLM inference)*: [Ollama](https://ollama.com/) with Gemma 2 (`ollama run gemma2`)

### Steps
1. Clone the repository:
   ```bash
   git clone https://github.com/Ayushgupta1715/khatasnap-ai.git
   cd khatasnap-ai
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the local development server:
   ```bash
   npm run dev
   ```

4. Open your browser at `http://localhost:5173`.

5. *(Optional)* Start Ollama in the background:
   ```bash
   ollama serve
   ```
   KhataSnap will automatically detect your local daemon and switch to live Gemma 2 inference!
